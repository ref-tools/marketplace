# Security Policy

## Supported versions

Security fixes apply to the latest commit on `main` of this repository.

## Scope

This policy covers the skills and plugin manifests in this repo (Claude Code and Codex marketplace entries, `SKILL.md` files, and related plugin config).

Issues with Ref's hosted APIs or product should go to Ref at [https://ref.tools](https://ref.tools), not through this repository's issue tracker.

## Reporting a vulnerability

Please report vulnerabilities through GitHub private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Do not open a public issue for a security report. We will acknowledge reports and work with you on a fix and disclosure timeline.
