# Security Policy

## Supported versions

Security updates apply to the plugins and skills in the default branch of this repository.

## Scope

This policy covers:

- Skills and plugin manifests in this repo (Claude Code and Codex marketplace entries, MCP configs, and skill content)

It does **not** cover Ref's hosted API or app. Report those to [Ref](https://ref.tools).

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability):

1. Open this repository on GitHub
2. Go to the **Security** tab
3. Choose **Report a vulnerability**

Do not open a public issue for security reports. We will acknowledge privately and coordinate a fix.
